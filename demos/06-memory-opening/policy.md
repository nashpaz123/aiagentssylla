# Refund policy (demo)

1. Refunds up to **100 ILS** inclusive are approved automatically (`route=auto`, `status=approved`).
2. Refunds **above 100 ILS** require a human agent before any commitment (`route=hitl`, `status=pending_human`).
3. Never invent a prior request — only use what is in `out/store.json`.
4. Never store card numbers, passwords, or secrets in the store.
